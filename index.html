왜 이 크롤러인가

실제로 테스트를 거쳐 검증된 4가지 핵심 기능

🛡️

robots.txt 자동 확인

요청 전 항상 규칙을 확인해, 명시적으로 금지된 사이트는 크롤링하지 않습니다.

🔁

자동 재시도 + 중간 저장

네트워크가 끊겨도 자동 재시도하고, 페이지마다 즉시 저장해 데이터 손실을 막습니다.

📊

4가지 출력 형식

CSV, Excel, JSON, 그리고 가격 이력이 쌓이는 SQLite까지 한 번에 저장합니다.

🤖

AI 기반 확장 크롤링

셀렉터가 없는 낯선 사이트도 AI가 대신 읽어 상품 정보를 추출합니다.

🛡️

무단 크롤링을 하지 않습니다

모든 요청 전에 대상 사이트의 robots.txt를 자동으로 확인합니다. 명시적으로 금지된 경로는 수집을 시도하지 않고 즉시 중단하며, 그 이유를 명확히 알려드립니다. 실제 개발 중에도 이 기능 덕분에 특정 연습용 사이트가 크롤링을 금지하고 있다는 걸 발견해 대상을 교체한 이력이 있습니다.

이런 경우 문의하세요

아래는 실제로 자주 있는 요청 유형입니다. 딱 맞는 상황이 없다면 마지막 "기타 문의"로 편하게 남겨주세요

01. 기본 수집
일회성으로 상품 데이터가 필요할 때
"경쟁사 사이트 상품이랑 가격을 엑셀로 정리해주실 수 있을까요?"
python scraper.py --pages 3
→ CSV·Excel·JSON·DB 4가지 형식으로 결과물 전달
02. 정기 추적
가격 변동을 계속 모니터링하고 싶을 때
"매주 가격이 바뀌는지 계속 체크하고 싶어요. 특히 이 상품은 꼭 추적하고 싶어요."
python scraper.py --history "상품명"
→ 정기 실행으로 이력이 쌓이고, 변동 시점을 즉시 확인
03. 긴급 대응
셀렉터가 준비 안 된 낯선 사이트를 급하게 봐야 할 때
"내일 미팅 전까지 이 사이트 상품 목록이 필요해요. 시간이 없어요."
python scraper.py --ai-url "..."
→ AI가 즉시 추출 (텍스트 정보는 정확, 아이콘형 정보는 제외)
04. 정책 확인
요청한 사이트가 크롤링을 허용하는지 궁금할 때
"이 사이트도 크롤링해서 매일 모니터링 좀 해주세요."
robots.txt 자동 확인 → 금지 시 즉시 중단
→ 무리하게 진행하지 않고, 가능한 대안을 함께 제안
05. 기타 문의
위 4가지에 딱 맞지 않는 경우
다른 형태의 데이터 수집, 맞춤 자동화, 견적 문의 등 무엇이든 남겨주세요.
